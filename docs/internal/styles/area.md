# Area interface references

The [OpenAI case study](https://www.area.tech/openai) describes Area's 2023
identity and ChatGPT interface explorations. Its [sidebar](https://pub-c9496d20dacb40f4874f191a2686b638.r2.dev/openai/Sidebar.png)
and the Writer, character-tag, tool dock, and code demonstrations show a soft,
colourful interface rather than a hard-edged editorial grid.

Observed in the images:

- Rounded filled user messages and a large matching composer, with coloured
  character tabs rising above it. Mentions appear as inverse chips.
- Unboxed serif assistant text in the character colour, with a character icon
  at the left and a small Regenerate action below.
- A pale sidebar with a serif wordmark, outlined rounded new-conversation
  control, uppercase history label, coloured dots and a filled selected row.
- Rounded tool containers with a centred icon and title, segmented navigation,
  actions, and an attribution/action footer. The code example has a dark panel.
- Blue, orange, purple and yellow distinguish characters. UI and user text use
  sans serif; the assistant's prose uses serif. Colour contrast varies by image.

For Mast, mapping a stable chat or harness identity to theme-supplied colours,
using Geist and an openly licensed serif, and adapting the tool controls to
Mast's actions are **inferences**, not details established by the case study.
Theme and style remain independent; neither the source palette nor a fixed hue
is required by the shape of the interface. Motion is not established by these
still images.

The optional Area themes derive six identity colours from their ANSI palette.
Purple (#8B7CF6) is an additional Mast palette colour: the requested Cofactr
swatches did not include a purple. The pale blue-white sidebar and dark blue
surface are adaptations of the reference rather than sampled brand colours.
