# Reuse work structures

A **Blueprint** copies a saved item tree once. Right-click an item and choose **Save as blueprint…**, then use **New from blueprint…** under the desired parent. The copy contains the saved structure and instructions; chats and requests are not copied. Changes to the blueprint do not automatically change existing copies. When a linked blueprint changes, review its proposed updates before accepting them.

A **Child template** belongs to a parent item and supplies structure and live instruction rules to its direct children. Set it up in the parent's details. New children follow it; for an existing or moved-in child marked as not following the template, use **Apply child template…** to opt it in. Later rule changes apply to followers. Use a Blueprint to copy a tree; use a Child template for rules shared by children of a container.
