# Friction and status

## Review friction

Open the Space root's details and find **Friction**. Agents can report obstacles, and Mast can capture events such as refused tool calls, approval prompts and turn errors when auto-capture is enabled. Filter and expand reports, then use **Create bug**, **Propose instruction**, or **Dismiss**. You can export Markdown or import an existing friction log. Reports with the same fingerprint collect occurrences. **Approvals** limits the list to approval prompts, the search box filters by command, reason or outcome, and **Create rule…** on an approved Codex command drafts an approval rule for you to review and save (see Approval history in the Work Outline guide).

## Use the menu bar

Enable the menu bar item in settings. Its lamp reflects chat status and its menu shows account usage and reset times, chats needing you, and interrupted chats. Select a chat to open it; use **Resume all** for interrupted work. When a newer build is installed, the menu also offers **Restart when idle**. It includes **Open Mast** and **Quit**.

With **Needs you** enabled for the menu bar, **Dismiss all** beneath **Requests** dismisses the Required Actions listed in that menu. It uses the same dismissal as each request's card and opens Needs you so any delivery errors are visible. Requests arriving afterward stay open; waiting or failed chat notifications are unchanged.
