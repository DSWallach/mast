- Agents: add the `build_enqueue`, `build_status`, `build_list`, `build_wait`, `build_log` and `build_cancel` tools. A command that matches no Space approval rule waits for your approval on a card that shows the whole command. Queued builds accept a fixed list of Cargo flags, are refused in read-only chats, and are shared only within a Space.
- Agents: Worker and Verifier tool lists are enforced by the engine on agent tool calls. Verifier chats get a read-and-review list without `run_command`; they can read builds only for chats on their own work item.
- Builds: the build queue is off until `build-queue.json` in the engine data dir describes a build host. Slot checkouts are now moved only inside the host's slot lock, and a start whose answer was lost is fenced on the host before it is retried, so a build host can be shared safely.
- Builds: `remote-cargo.sh status` and `stop` no longer report a job that finishes while they are checking it as dead, which could mark a successful build `lost`.
