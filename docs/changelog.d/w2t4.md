# W2-T4: instruction channel and account pins

- Pi, Grok, Devin, Hermes and opencode receive Work Outline instructions on the first prompt of a new session (instruction channel `FirstTurnPrompt`). The envelope is re-sent only when its revision changes.
- A revision change on those harnesses starts a fresh session only after the user confirms the context reset (`FreshSession`). Nothing is discarded automatically.
- `create_chat` with `workItemId` reuses a chat only when it matches the explicit `harness`, `model` and `accountId`. An `accountId` must be the caller's own managed account for that harness, and the engine refuses any other.
- A `/command` first turn that needs Work Outline instructions is refused rather than sent without them.
