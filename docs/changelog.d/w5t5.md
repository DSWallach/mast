# W5-T5: scheduled pins flow and cache performance

- The `scheduled-pins` UI flow now starts with nothing pinned, pins from the row menu, collapses, restarts the app, runs the pinned task and unpins it. The UI driver gains `right_click` and `restart` steps.
- The SWR cache (Linear and PR lists) no longer serializes the whole cache while holding its lock; at 32 cached keys a refresh used to block readers for about 20 ms and now blocks them for under 1 ms.
- Overview List mode is unchanged: measured at 250 and 1,000 chats, nothing beat the baseline by more than 2× MAD.
