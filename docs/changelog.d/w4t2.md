# W4-T2: quota broker

- New `mast_engine::quota_broker`: polls Antigravity, Claude Code and Codex usage every 90 s (180 s for `agy /usage`) only while orchestration is active, never refreshes single-use OAuth tokens, and falls back to local token usage when a probe fails.
- `BalancedFailover` (default): dispatch is weighted by headroom below the 85% hard cap, stays on the current provider until 78%, and pauses automatically (with the earliest reset) when every provider is at cap.
- `PinnedFreeze`: never fails over; at 90% it freezes, checkpoints and notifies.
- Follow-up (needs W3-T2 to land): wire `QuotaBroker::status_payload()` (under 550 B) into the `quota_status` tool and `wake_header()` as a one-line header above the soft cap. Requires admission to `tool_catalog.rs`, `agent_tools.rs` and `crates/proto/**`.
