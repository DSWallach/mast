# W4-T2: quota broker

- New `mast_engine::quota_broker`. It is not wired into orchestration yet, so Mast's behaviour does not change.
- It polls Antigravity, Claude Code and Codex usage every 90 s (180 s for `agy /usage`) only while orchestration is active, never refreshes single-use OAuth tokens, and falls back to local token usage when a probe fails. A provider that needs sign-in or has unknown usage is never dispatched to.
- `BalancedFailover` (default): dispatch is weighted by headroom below the 85% hard cap, stays on the current provider until 78%, and answers `PauseAll` with the earliest time to try again when no provider is eligible.
- `PinnedFreeze`: never fails over; answers `Freeze` when work would pass 90%.
- Dispatch reserves its cost atomically. A successful poll drops reservations at least one poll interval old.
- Upcoming (needs W3-T2 to land): act on `PauseAll` and `Freeze` (pause, freeze, checkpoint, notify), wire `QuotaBroker::status_payload()` (under 550 B) into the `quota_status` tool, and add `wake_header()` as a one-line header from the soft cap. Requires admission to `tool_catalog.rs`, `agent_tools.rs` and `crates/proto/**`.
